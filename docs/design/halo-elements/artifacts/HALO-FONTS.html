That mapping treats type as a swap with no candidate on the other side. This is the candidate list: the faces the games actually shipped, matched to open-source stand-ins, driving the same surface four times.

The same surface, four times

Field Calls housing, a unit board, a slot rack, one prose line, three chips. Geometry, colour and the mono stamp voice are frozen across all four — the display and body faces are the only variable, so anything you see is the type doing it.

The read

Judged against the two standing constraints: "industrial rental yard before western", and never a third family (wrangler-style §2).

Recommend

Infinite — Industry over Archivo

It is the only scheme that adds nothing to the family count in the body: Normative and Archivo are near-interchangeable, so the change is one display face on housing titles and unit names. Yard-legible at 11px, and it never reads western.

Strong second

Reach — TV Nord

Zero new families: Archivo Narrow is a width of a face already locked. Buys real condensed display room for long unit names, which the board needs. Least distinctive of the four — it looks like good signage, not like Halo.

Reject for UI

Combat Evolved & Halo 3

Orbitron's wide round caps eat the housing bar and cost the descriptor line its space. Conduit is the most Halo-looking, and that is the problem — it collides with the mono stamp voice, so chips and labels stop being a separate register.

None of the real Halo faces are here. Every one of them is a licensed retail font; buying one for a public web app means a webfont licence priced per pageview, and the app is served from public Pages. Everything above is an OFL stand-in, embedded in this page as a data URI so it renders without a CDN.

The stand-ins are the shippable answer, not a placeholder for one. Swapping any of them into the app is one Google Fonts line in index.html, the same way Archivo already ships (wrangler-style §2). If a real face is ever bought, it drops into the same slot.

Nothing here is a decision yet. No ledger row was added — pick one and it gets written up as a MOCKUP-mode type row against #215.

How to drive this part. The root is position:absolute; left:var(--x); top:var(--y) — set --x/--y and drop it anywhere. Everything inside is measured from the part's own top-left, so nothing is tied to the original canvas.

Knobs. --x/--y placement · --w overall width (default 914.5px) · --f1/--f2 on .pf-fct, the vertical fade stops of the top chamfer facet. (.pf-fcb declares --f1/--f2 too, but re-declares its whole background with the numbers inlined, so on the bottom facet they are inert — kept verbatim from the source.)

--w does not really scale the art. Only the right-hand edge assembly (.pf-rmar, .pf-rface) and the stretchy .pf-body/.pf-bl* boxes track it. .pf-railR (left:807px), .pf-cav (left:31.5px; right:18px), .pf-riv (left:896.5px) and every .pf-r*/.pf-bl* 90° gradient are baked to a ~910px body. Straying far from ~915px desyncs them from the right edge. Height is hard-coded 125px — not a variable.

The painted box is bigger than the nominal box. .pf-blt (top:−1px) and .pf-blb (top:125px) are siblings of .pf-body, so they escape its clip-path — painted height is 127, not 125. .pf-brk is a sibling too and carries filter:blur(.45px) on the whole group, so the red C bracket is not clipped by the metal silhouette and bleeds ~1px past its own rects. The root sets no overflow — size any consuming layout generously.

It assumes a --bg backdrop. .pf-fct/.pf-fcb bake #0a0c10 into their vertical gradients as the fade-to-nothing colour. On any other background the left end reads as a dark halo. That is source artwork, preserved as-is.

Why these preview stages are 264px tall. Below a ~256px layer height Chromium takes a different raster path and lands the .pf-rface chrome-edge gradient bands one pixel left of where a normal-sized layer puts them. The stages here clear that threshold so what you see is the true render. The pixel-gate page (c4-panel-frame.verify.html, a fixed 944×157 box) sits below it and therefore shows that 1px artefact — verified to be identical for the untouched original markup, so it is the renderer, not the part.

.is-banner · the outer chrome frame + interior vertical build-up · 1 instance · canvas (1, 125), 1287x254, band B · sets --x/--y only (own box is fixed 1287x254)
shown here at --x:20px; --y:20px on a demo stage so the whole shell is visible with breathing room — on the real canvas it sits at --x:1px; --y:125px and is a SUBSTRATE: c10's banner-top-row covers its top 116 rows, and c9/c4b/c3b/c1b/c1c/c2b/c2c/ c5b cover most of what remains. Only thin strips of .face and the .rim-* edges ever show through in the assembled page — this preview is the only place you see the whole thing at once.
How to drive this part. The root is position:absolute; left:var(--x); top:var(--y), fixed at 1287x254 — set --x/--y (or apply .is-banner, which sets them to the canvas instance's own 1,125) and drop it anywhere. There is exactly one instance in the source mockup, so there is exactly one variant class.

Nothing inside moves. .back, .face and the four .rim-* strips were already positioned relative to #banner in the original (their own position:absolute makes #banner the containing block) — the rebase here is only the ROOT's left/ top, which the original hard-coded with no vars at all. Every descendant offset below the root is unchanged, byte-for-byte, from original.html lines 488-518.

The insets are asymmetric on purpose. .rim-t starts left:12px while .rim-b starts at 6, .rim-l at 5 and .rim-r at right:1px; .face is inset left:7 right:7 top:5 bottom:1. These are measured values from the reference, not a mistake to square up.

Verify is null for this part. It is a band-B-only substrate — there is no window of original.png that shows it uncovered, so check.py has no honest crop to run against. See housing.verify.html for the full-canvas isolation diff that stands in for the pixel gate; the real gate runs at assembly time once c9/c10/c11/c12 are composited on top of it.

How to drive this part. The root is position:absolute; left:var(--x); top:var(--y) — set --x/--y and drop it anywhere. Every child is measured from the part's own top-left, so nothing here is tied to the original canvas.

Knobs. --x/--y placement · --w/--h the plate's own painted box · --hx/--hy/--hw/--hh the hairline ring's box — a MEASURED, asymmetric rect, not centred in the plate and not derivable from --w/--h by any formula · --glass the glass tint, feeding both .glass and the small glass-coloured disc inside .hair > i that punches the ring's centre back out, leaving only a 1px cyan hairline.

Not a knob. Each layer's own chamfer radius (--cut, feeding the shared .oct4 clip-path from tokens.css) is fixed per layer and does NOT scale with --w/--h: .body 19px, .glass 15px, .hair 12px, .hair > i 11.4px.

The "FAILED" readout. In the original this was a raw, unclassed <div> with a wholly inline style block — the one un-classed rule in the whole component. It is now a real class, .readout, carried value-for-value (var(--mono), weight 700, 40.4px, line-height 1, letter-spacing -0.1px, colour #f4595a, text-shadow 0 0 6px rgba(244,95,91,.40), at local (38px, 32.7px)). It ships only on .is-failed's markup — include the <div class="readout"> child yourself; the class alone does not add the text.

Painted box == nominal box. Unlike some parts in this kit, neither instance spills past its own --w×--h rect — no glow, no blur, no bloom escaping the chamfered edge. C5a additionally touches canvas row 0 in the source mockup; that is the real top of the paint, not a box clipped by the canvas edge.

How to drive this part. The root is position:absolute; left:var(--x); top:var(--y) — set --x/--y and drop it anywhere. Every instance's OWN geometry is fixed (9x9 rivet, 30x31 hexicon, shrink-to-fit name text); only placement varies, which is why there is no --w/--h family here the way c5's plate has one.

Three unrelated marks, one file. .is-rivet, .is-hexicon and .is-name share no structure or styling — they were bundled here because the source canvas placed each as one loose, unwrapped element with nothing else around it. Picking a variant class is not "configuring" a shared shape, it is picking WHICH mark you want.

Paint order matters on the real canvas. Every instance of this part sits on top of another part's paint (R1-R3 on c5's C5b, R4 on c10's .bt-rivet, .is-hexicon/.is-name on c4's C4b) — this sheet only draws the mark itself; stacking order is the consumer's job at assembly time.

Not a knob. .is-name's font — Arial Bold, 41.9px, letter-spacing -.35px — is a MEASURED fit against the reference glyph widths, not a preference. Do not substitute a font, and keep tokens.css's .stage { font-kerning: none } in effect wherever this part is dropped; the metrics were measured with kerning off.

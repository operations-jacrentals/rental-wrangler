Signal — a coloured chip reporting read-only state. Not tappable to change it. Colour = state, fill = today. Click teleports to the source record.
Outline · changed 2026-07-25, border thickened 2026-07-28 (ledger #140). The secondary chip is a true outline: transparent background plus a 1.5px border (was 1px) in its own status hue. It used to be a tinted backfill (--gray-bg, --blue-bg …), which read as a third, muddier fill state rather than as the honest "same state, not today." The --*-bg tokens stay — plates still use them for section headers — they just no longer back a chip. Red is the one hue that changes token when outlined: it uses --red-line, a lighter red that clears the contrast floor on the dark panels once the tint is gone. Chips are also radius 0 now (--chip-radius: 0, ledger #140 — was 7px, then 2px) and a filled Signal wears the machined ring finish instead — see Size, control & radii.
